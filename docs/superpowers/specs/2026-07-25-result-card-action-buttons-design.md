# 検索結果カードのアクションボタン4種 企画書

- 作成: 2026-07-25 / 起案: ユーザー要望
- 状態: **企画段階・実装未着手**(ユーザーレビュー待ち)
- 対象: iOSアプリのみ(サーバー変更なし)

## 目的

スキャン直後のカード上で「仕入れ登録」と「他販路の相場確認」を1タップで行えるようにし、
仕入れ判断のスピードを上げる。現在カード下部を占有している「仕入れリストへ追加」ボタンを
カード右側の空きエリアへ移して省スペース化する。

## 配置

スキャン結果カード右側の空きエリア(ISBN・ランキング列の右隣)に、**2×2のコンパクトな
ボタングリッド**を置く。

```
┌─────┬────────────────────────────┐
│ 画像 │ タイトル                      │
│     │ [barcode] 9784…   ┌────┬────┐│
│     │ ランキング: 20万位  │仕入れ│Amazon││
│     │                  ├────┼────┤│
│     │                  │メルカリ│価格.com││
│     │                  └────┴────┘│
└─────┴────────────────────────────┘
```

- 各ボタンは**正方形風の角丸ボタン**(RoundedRectangle)で、1文字表記:
  仕入れ=「仕」/ Amazon=「a」/ メルカリ=「m」/ 価格.com=「価」。色は実装者裁量。
- ブランド・サイズ・重量表示は**機能ごと廃止**(ユーザー決定 2026-07-25)。iOSの表示・モデル、
  サーバーの取得処理(Keepaのbrand/packageLength等のマッピング・無効化済みのSP-API補完フラグ一式)も削除し、
  右エリアはボタングリッド専用にする。
- **既存の「仕入れリストへ追加」ボタン(カード下部の横長ボタン)は削除**する。
  商品詳細画面(ProductDetailView)の追加ボタンは今回触らない。

## ボタン仕様

| ボタン | 動作 | 表示条件 | ゲート |
|---|---|---|---|
| 仕入れ | 仕入れフォーム(新規追加)をシートで開く(現行ボタンと同じ挙動・追加済みならチェック表示+無効化) | ASINあり | **Pro限定**(現行踏襲) |
| Amazon | `https://www.amazon.co.jp/dp/{ASIN}` を外部ブラウザで開く | ASINあり | 無料も可 |
| メルカリ | `https://jp.mercari.com/search?keyword={商品名}` を外部ブラウザで開く | タイトルあり | 無料も可 |
| 価格.com | `https://kakaku.com/search_results/{商品名}/` を外部ブラウザで開く | タイトルあり | 無料も可 |

- 商品名はURLエンコードして使う(タイトル全文。副題・シリーズ括弧も含む。
  検索精度が悪ければ後で「括弧以降を落とす」等の調整余地あり)
- 見つからない(unresolved)カードではグリッド全体を非表示
- 無料ユーザーの「仕入れ」ボタン: 非表示(現行の追加ボタンと同じ扱い)。
  外部リンク3つは無料でも使える(アプリの利便性でスキャン利用を促す狙い。
  Pro限定にしたい場合は要指示)

## 外部リンクの開き方

- `UIApplication.shared.open`(既定ブラウザ)で開く。メルカリはユニバーサルリンク対応のため、
  メルカリアプリがあれば自動でアプリが開く(こちらで制御は不要)
- アプリ内WebViewは使わない(メルカリ規約リスク回避。2026-07-25の法的確認どおり)

## 法的・表記上の配慮(確認済み方針)

- ボタンは**テキスト表記のみ**(「メルカリ」「価格.com」)。各社ロゴ画像は使わない
- 単なる外部リンク(検索URL)のため法的リスクは実務上問題にならない水準
- スクレイピングや相場データのアプリ内取り込みはしない

## 実装範囲

- 変更: `SearchTabView.swift`(ボタングリッド追加・既存追加ボタン削除・ブランド/サイズ/重量表示の削除)、
  `SearchModels.swift`(brand/dimensionsMm/weightG削除)、サーバー(keepa/routesの同フィールド生成処理と
  SP-API補完フラグ一式・関連テストの削除)。新規ファイルなし(グリッドが大きくなるようなら
  `ResultCardActionButtons.swift` として切り出し可)

## やらないこと(YAGNI)

- メルカリ・価格.comの相場データのアプリ内表示(法的リスク)
- ロゴ画像の使用
- 商品詳細画面へのボタン追加(要望があれば別途)
- リンク先の売れ行き分析等の付加機能

## 検証方針

- Debug/Releaseビルド成功
- シミュレータ(開発用Proトグル使用): 4ボタンの表示・仕入れフォームが開くこと・
  各リンクがSafariで正しいURLを開くこと(ASIN/商品名のエンコード確認)・
  無料時は仕入れボタンのみ非表示になること・unresolved時は全非表示
- 実機: メルカリアプリがある端末でユニバーサルリンクがアプリを開くこと(ユーザー確認)
